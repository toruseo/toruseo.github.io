UXsim: An open source traffic simulator in Python

This is the portal site for the open source and free traffic flow simulator UXsim and related software. You can access the latest version of the simulator from GitHub. This page collects the pages of UXsim and related simulators in one place. For details, please refer to the dedicated sites and materials.

UXsim is an open source and free macroscopic and mesoscopic traffic flow simulator written in Python. With Python coding, you can simulate large-scale traffic flow consisting of tens of thousands of vehicles in urban areas simply and quickly.

UNsim

UNsim is an advanced macroscopic traffic flow simulator. Like UXsim, it is based on Python and has a similar syntax, but it supports GPU computation and automatic differentiation via JAX. It enables ultra-fast parallel simulation that computes 1 million vehicles in a metropolitan area in 0.2 seconds, as well as optimization using automatic differentiation.
